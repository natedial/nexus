07 · interpretation

Separate the observation from the reading

Reading the pattern. The latest increase is broad, but Segment B is closest to its eight-week high. That is a descriptive observation; the sample does not establish a cause.

Borrow annotation for one sentence that changes how the reader interprets a chart. Keep attribution and uncertainty precise.

14 · provenance

Keep method and source on the printed page

Source: Illustrative local sample, prepared solely for this pattern library. Window: Eight weekly periods. Method: Percentage-point changes are current minus prior; missing comparisons are omitted, never imputed.

Stress check Replace this line with the real source, retrieval date, calculation, sample size, and any material exclusions.

Print defaults

  • Letter page; explicit page containers and folios.
  • Keep panels whole with break-inside: avoid.
  • Preserve subtle fills with print-color-adjust: exact.

Data handoff

  • Render exact values and sources from data, not CSS.
  • Use inline SVG only for plotted geometry.
  • Check grayscale legibility and PDF page breaks.
